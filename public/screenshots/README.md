## Screenshot Guidelines

- **Real screenshots only** - no AI-generated UI, no stock images
- **High quality** - clear, sharp images
- **16:10 aspect ratio** - matches the card design
- **Minimum 1280x800px** - ensures crisp display on all screens
- **Full page or key interface** - show the most representative view
- **No browser chrome** - clean screenshots without browser frame
- **Optimized file size** - keep under 500KB per image for performance
- **PNG format** - for best quality with transparency support if needed
